# ✝️ Synksar Auto Publisher (የስንክሳር አውቶማቲክ አሳታሚ)

**Synksar Auto Publisher** የኢትዮጵያ ኦርቶዶክስ ተዋሕዶ ቤተክርስቲያን ዕለታዊ የስንክሳር ምስሎችንና ሙሉ የአማርኛ ጽሑፎችን በየቀኑ በኢትዮጵያ ሰዓት አቆጣጠር እኩለ ሌሊት (**12:00 AM / 00:00 - Africa/Addis_Ababa**) ወደ ቴሌግራም ቻናልዎ በራሱ የሚያትም የተሟላ ዘመናዊ አውቶሜሽን ሥርዓት ነው።

የአንድ ሙሉ ዓመት (13ቱ ወራት፤ 365 ወይም 366 ቀናት) ምስሎችንና ጽሑፎችን **አንድ ጊዜ ብቻ** በማስገባት፣ ዓመቱን ሙሉ ያለምንም ሰው ጣልቃ ገብነት በራሱ ይሰራል።

## 🌟 ዋና ዋና ገጽታዎች (Features)

1. **ትክክለኛ የኢትዮጵያ የቀን መቁጠሪያ (13 ወራት)**፦
   - መስከረም እስከ ጳጉሜን (13ቱንም ወራት) እና የሰግር ዓመት (ዘመነ ሉቃስ - ጳጉሜን 6) በትክክል ያሰላል።
   - የግዕዝ ቁጥሮችን (፩፣ ፪፣ ፫... ፴) በራስ-ሰር ይለውጣል።
2. **አስተማማኝ የዕለት አሳታሚ (Scheduler)**፦
   - በየቀኑ 12:00 AM እኩለ ሌሊት በ Addisa Ababa timezone ይሰራል (APScheduler)።
   - **Offline Catch-Up / Recovery**፦ ኮምፒዩተሩ ወይም ሰርቨሩ እኩለ ሌሊት ላይ ጠፍቶ ቢሆን እንኳን፣ ዳግም ሲበራ የዛሬው ቀን አለመታተሙን አረጋግጦ ወዲያውኑ ያትማል!
   - **ድጋሚ ህትመት ጥበቃ (Idempotent)**፦ አንድ ቀን ቀድሞ ከታተመ በስህተት ድጋሚ እንዳይለጠፍ ይጠብቃል።
   - ያልተሳካ ህትመት ሲያጋጥም እስከ 3 ጊዜ በ exponential backoff ድጋሚ ይሞክራል።
3. **የተጠቃሚው ኦሪጅናል የፖስት ቅርጸት**፦
   - ከላይ፦ የዕለቱ ውብ የስንክሳር ምስል ($960 \times 1280$)
   - ከስሩ፦ የመክፈቻ ጸሎት + የቅዱሳኑ ዓመታዊና ወርኃዊ በዓላት ዝርዝር + የቴሌግራም ቻናልና ግሩፕ ሊንክ + የሰንበት ትምህርት ቤቱ ስም (**የቦት ሊንክ አልተካተተም!** እንደተጠየቀው)።
   - የቴሌግራም የካፕሽን ገደብ (1024 ፊደላት) ሲያልፍ፣ ምስሉንና ሙሉውን ጽሑፍ በንጽህና ተከታትሎ ይልካል።
4. **ዘመናዊ የድር ዳሽቦርድ (Web Dashboard)**፦
   - በስልክና በኮምፒዩተር የሚሰራ ውብ ዳሽቦርድ (Flask)።
   - የ13ቱ ወራት እና 366 ቀናት የቀለም አመልካች ካላንደር (አረንጓዴ = ሙሉ፣ ቢጫ = ምስል ብቻ፣ ቀይ = ባዶ)።
   - የቀን ይዘት ማረሚያ (Editor) በቀጥታ የቴሌግራም ቅድመ-ዕይታ (Live Preview)።
   - ትላልቅ ዓመታዊ የዚፕ ማህደር (Annual ZIP) መጫኛ እና የይዘት ማረጋገጫ (Validation) ሪፖርት።
5. **የአስተዳዳሪ ቴሌግራም ቦት (Admin Bot)**፦
   - 12 የተሟሉ ሜኑዎች (የዛሬን እይ፣ የነገን ቅድመ-ዕይታ፣ የሙከራ መልእክት ላክ፣ ይዘት አርትዕ፣ ምስል ተካ፣ ጽሑፍ ተካ፣ ህትመትን አቁም/አስጀምር ወዘተ)።
   - ከሌላ ቻናል ፎርዋርድ የተደረገ ፖስትን በቀጥታ የመቀበል ችሎታ።
   - ለተፈቀደላቸው አስተዳዳሪዎች ብቻ የተከለለ ደህንነት።

## 🚀 ፈጣን አጀማመር (Quick Start)

### ፩. ቅድመ-ዝግጅት እና ማዋቀር

በፕሮጀክቱ ማውጫ ውስጥ የሚገኘውን `.env` ፋይል ከፍተው የራስዎን የቴሌግራም መረጃዎች ያስገቡ፦

```env
# 1. ቴሌግራም ቦት ቶከን (ከ @BotFather ያገኙትን)
BOT_TOKEN=7123456789:AAFxxxxxxxxxxxxxxxxxxxxxxxxx

# 2. የቴሌግራም ቻናል መታወቂያ (ቦቱን በቻናልዎ ላይ Administrator አድርገው ይጨምሩት!)
CHANNEL_ID=@atsedetiguhan

# 3. የእርስዎ የቴሌግራም ID ቁጥር (በ @userinfobot ማወቅ ይችላሉ)
ADMIN_IDS=123456789

# 4. የሰዓት ዞን እና ሰዓት (እኩለ ሌሊት 12:00 AM)
TIMEZONE=Africa/Addis_Ababa
PUBLISH_HOUR=0
PUBLISH_MINUTE=0
```

### ፪. ስርዓቱን ማስነሳት

ሁሉንም አገልግሎቶች (Scheduler, Web Dashboard, Telegram Bot) በአንድ ላይ ለማስነሳት፦

```bash
python main.py
```

የድር ዳሽቦርዱን በኮምፒዩተርዎ ወይም በስልክዎ ብሮውዘር ይክፈቱ፦
👉 **http://localhost:5000**

## 🛠️ የትዕዛዝ መስመር አማራጮች (CLI Options)

- **ሁሉንም በአንድ ላይ ለማስነሳት**፦
  ```bash
  python main.py
  ```
- **የድር ዳሽቦርዱን ብቻ ለማስነሳት**፦
  ```bash
  python main.py --web
  ```
- **የቴሌግራም ቦትን ብቻ ለማስነሳት**፦
  ```bash
  python main.py --bot
  ```
- **የጊዜ ሰሌዳውን (Scheduler) ብቻ ለማስነሳት**፦
  ```bash
  python main.py --scheduler
  ```
- **የዛሬን ስንክሳር አሁኑኑ ወደ ቻናሉ ለመላክ (ሙከራ)**፦
  ```bash
  python main.py --publish-today
  ```
- **የይዘት ማረጋገጫ (Validation) ሪፖርት ለማየት**፦
  ```bash
  python main.py --validate
  ```
- **ፈተናዎችን (Tests) ለማስኬድ**፦
  ```bash
  python -m unittest tests/test_all.py
  ```
